## 1. Purpose
Deter, detect, and mitigate insider threats to classified information, people, and facilities, while
protecting employee privacy and civil liberties.

## 2. Governance
- **ITPSO** - a U.S. citizen employee appointed in writing, cleared at the facility level, listed as
  key management personnel, with authority to run the program (117.7(b)(4)).
- **FSO** - serves as ITPSO or is an integral member of the program team.
- **Program team** - [security, HR, IT/cybersecurity, legal, as appropriate].
- **Entity families** - if one ITPSO covers several cleared entities, note each separate
  appointment and the implementation plan required by the ISL.
